# 成長ログ

自分用の習慣・学習記録アプリ（スマホのホーム画面に置いて使う形）。

- 記録はスマホの中（ブラウザの保存領域）だけに保存する。サーバーには送らない。
- 週1回、設定の「保存する」からバックアップファイルを作り、Googleドライブに保存する。

## 第1段階でできること
- 今日：睡眠、今日の目標、夜のふりかえり（仕事の調子・だらだら時間・節約）、「YouTube見たくなった」ボタン
- 飲み会：種類ごとの杯数、月ごとの回数、翌朝チェックリスト
- 筋トレ：曜日ごとのメニュー、セットごとの重さ×回数、前回の記録、週の回数
- 学び：英語の時間と4技能、本棚と15分ごとのつぶやき、言葉の手帳
- 相談：コンサルテーションの件数・結果を治療ごとに記録（金額は暗号化）
- ふりかえり：週のまとめ、飲み会の翌日とふだんの比較

## ファイル
- `index.html` / `style.css` / `app.js`：アプリ本体
- `sw.js`：電波がなくても開けるようにする仕組み
- `manifest.webmanifest`、`icons/`：ホーム画面に置くための設定とアイコン
